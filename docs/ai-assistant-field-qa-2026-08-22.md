## Повторяющиеся дефекты

1. **S0 — неверная идентификация гибридной трансмиссии.** Нельзя предлагать/выполнять сервис по ветке 0BK для Q5 Hybrid 0BW.
2. **S1 — условная техническая ветка помечается как «Стоимость подтверждена».** Она затем меняется на другом прогоне без новых фактов.
3. **S1 — Local First нарушен.** В traces есть совместимый остаток Valvoline, но итог блокируется из-за ROSSKO либо выбирается дорогая позиция поставщика.
4. **S1 — фильтр и расходники не согласованы.** В ряде ответов техкарта обещает замену фильтра, но позиции отсутствуют в смете и тексте клиенту.
5. **S1 — вычислитель сметы даёт ложные блокировки** `Количество основной жидкости не совпадает с расчётным объёмом` при заполненной совместимой позиции.
6. **S2 — нарушен контракт вывода.** Часть одинаковых запросов вместо техкарты/сметы возвращает неструктурированное «техническое резюме».
7. **S2 — клиентские тексты нередко содержат висячее `VIN` без значения.**
8. **S2 — traces смешивают контекст предыдущего диалога** при последовательном использовании вкладки: в разных запусках после актуальных источников видны источники предыдущего VIN.
9. **S2 — доступность модели неустойчива.** Повтор Pajero завершился ошибкой подключения OpenAI из server runtime.

### Исправленные root causes

1. **Слабый контракт технической ветки.** VIN-резолвер теперь передаёт свой snapshot в серверный builder; заявленная МКПП блокирует ATF-сценарий. Для семейства Audi Q5 Hybrid добавлен safety-profile по агрегату `0BW` и `G 060 162 A2`, а не исключение по VIN.
2. **FilterPolicy была булевым набором.** Она стала структурированной: `presence`, `access`, `tgmAction`, `filterPartRequiredForQuote`, `panServiceRequired`, `reason`, `evidence`. Различаются внешний фильтр, сервисный поддон, интегрированный поддон и внутренний фильтр.
3. **Техкарта могла обещать не включённую операцию.** Каждая QuoteOption получила service package; пакет и строка сметы валидируются вместе. Обязательный фильтр/поддон или обязательный крепёж без строки в смете превращаются в machine-readable integrity blocker.
4. **OEM reference смешивался с продаваемым товаром.** Trace теперь отдельно хранит OEM requirement, OEM reference, compatible product и selected sellable product. В расчёт проходит одна основная жидкость с canonical billable quantity.
5. **Ошибки калькулятора маскировались под отсутствие тарифа.** Непредвиденный сбой получает `QUOTE_CALCULATION_ERROR`, а `MISSING_LABOR_RULE` остаётся только для фактического отсутствия правила работы.
6. **Раннер мог закончить свободным текстом.** После обязательного поиска локального каталога технический запрос принудительно завершает ветку через `build_quote_and_tech_card`; противоречивая инструкция о прямом вызове второго калькулятора удалена.
7. **Formatter оставлял `VIN` без значения.** Маркер VIN удаляется вместе с 17-значным номером; formatter использует только validated QuoteSet и его service package.

### Residual limitations / следующий field gate

- До live-прогона после deployment нельзя объявлять цель ≥90% first-run quote success достигнутой: для неё нужны актуальные OpenAI, TRONK, локальный каталог, тарифы и ROSSKO.
