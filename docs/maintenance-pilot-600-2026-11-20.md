- Сохранённая ручная связка больше не перекрывает противоречие двигателя, кузова, поколения или года. Для повторного использования её заданные признаки должны присутствовать; решение только по марке/модели не применяется к другой машине с неизвестным двигателем.
- Объём в склеенной записи `35TFSI1.5` распознаётся без превращения кода исполнения `203.045` в литры.
- Исправлены точное написание VW Tuareg/Touareg, разбор кузова Getz TB, поколений Polo V/RAV4 V и приоритет известного года автомобиля перед каталоговым диапазоном. Служебные строки PDF Ford не выдаются за модификации. Неизвестный двигатель при этом не назначается автоматически.
- Неизвестное включение фильтра не считается заполненным сервисным объёмом.
- Сведения для проверки остаются ручными подсказками и не становятся допуском, вязкостью или объёмом по умолчанию. Проверенный профиль сохраняет автоподстановку.
- Лимит 20 исследований в час снимается только во внутреннем пакетном режиме. Обычный HTTP API не получает этот флаг. Пакет повторно не исследует уже обработанную группу даже при изменении пропусков или истечении старого результата. Эта API-ветка в текущем прогоне не выполнялась.
