# Согласование очистки схемы после вывода интеграции

Статус: `migration_approval_required`.

Forward-only Prisma migration создана, но не запускалась. В ней установлен
обязательный `migration_approval_required` gate: без подтверждённого backup
PostgreSQL в Timeweb она завершится ошибкой до любого `DROP`.

После одобрения migration должна быть новой, forward-only и удалить только
следующее:

- три таблицы sync snapshots и состояния аналитики прежнего провайдера;
- устаревшие колонки внешних идентификаторов и ссылок в CRM и диагностике;
- относящиеся только к ним индексы.

До применения migration владелец должен приложить read-only evidence:

1. count строк каждой удаляемой таблицы и колонки;
2. JSON/CSV manifest внешних идентификаторов без секретов;
3. проверку nullable и foreign keys;
4. доказательство, что бизнес-сущности и их внутренние IDs сохранены;
5. verified Timeweb PostgreSQL backup с идентификатором и временем создания;
6. явное одобрение на создание и применение migration.

Автоматический deploy не должен применять schema changes. После получения
всех шести пунктов migration повторно проверяется на непроизводственной копии
БД и применяется только в согласованное maintenance-окно.
