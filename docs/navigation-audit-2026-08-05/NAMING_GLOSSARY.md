# NAMING_GLOSSARY

## Правила именования

- В навигации использовать язык задач и объектов автосервиса, а не названия моделей/провайдеров.
- Один термин имеет один смысл во всём продукте.
- Название провайдера показывается внутри задачи: «Записи · YCLIENTS», а не вместо задачи.
- PERSONAL обозначается притяжательным «Мой/Моя/Мои»; системное — существительным без притяжательного местоимения.
- Не смешивать русские и английские слова, кроме общеупотребимых брендов и терминов P&L/Cashflow с русским пояснением.
- Заголовок страницы может быть точнее пункта меню, но не менять сущность.

## Запрещённые неоднозначности

1. **«Кабинет»** без уточнения: не использовать после миграции labels.
2. **«Организация»**: не использовать одновременно для группы, филиала и юрлица.
3. **«Telegram»** без «Мой» или «Рабочий»: не использовать в настройках.
4. **«Уведомления»** без «Мои» или «Клиентские»: не использовать в глобальной навигации.
5. **«Аналитика»** без предмета: допустима только как локальная вкладка внутри уже известного раздела.
6. **«Контрагенты»** как единственный пользовательский вход: заменить на клиентское/поставщицкое представление.
7. **`BusinessGroup`, `owner/admin/master`, `internal · live data`** в обычном UI: показывать пользовательские русские эквиваленты; техническое — только в diagnostics.

## Шаблоны заголовков и breadcrumbs

```text
Верхний раздел / Подраздел / Объект

Работа / Отгрузки / № 1432
Клиенты / Дела / Иван Петров
Склад / Инвентаризации / ИНВ-0021
Управление / Филиалы / Дачная 6В
Управление / Интеграции / устаревшая складская интеграция
Мой профиль / Безопасность
```

Scope не заменяет breadcrumb и показывается отдельной стабильной меткой: `Филиал: Дачная 6В` или `Все филиалы`.

## Микрокопирайтинг доступа

| Не использовать | Использовать |
|---|---|
| «Недоступно» | «Нужен доступ: управление филиалами» |
| молчаливый redirect на Главную | экран «Нет доступа» + причина + сменить филиал/запросить доступ |
| «Операции недоступны» в all-mode | «Для создания выберите филиал» + кнопка выбора |
| «admin only» | «Доступно владельцу группы» или точное capability человеческим языком |
| «Ошибка 403» | «У вас нет права изменять банковское подключение» |
