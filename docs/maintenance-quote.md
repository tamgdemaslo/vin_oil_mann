# Единый расчёт ТО в отгрузке

Расчёт ТО раскрыт сразу в основной области создания и редактирования отгрузки, перед поиском позиций. В просмотре сохранённой отгрузки тот же компонент расположен перед вкладками состава, VIN и диагностики. Старые карточки «Готовый расчет ТО для клиента» удалены. Для начала расчёта автомобиль не обязателен: допуск, вязкость, объём и артикулы MANN можно указать вручную. Подбор автомобиля передаёт профиль и найденные фильтры в уже доступный расчёт; отдельного расчёта внутри подбора больше нет.

- Допуск, вязкость и объём выбираются через компактные поля с поиском по вводу: полный список открывается по фокусу или кнопке со стрелкой и прокручивается без ввода, доступны выбор мышью и стрелками/Enter, закрытие Escape и ввод собственного значения. Для допусков есть разделы «Автомобиль», OEM, ACEA, API и ILSAC. Ввод обновляет расчёт после паузы 350 мс; выбор из списка и уход из поля применяют значение сразу. Нормализованные требования автомобиля вычисляются повторно только при изменении профиля. Для нестандартных значений есть ручной ввод.
- Единственный нормализованный допуск, вязкость и точный объём проверенного профиля подставляются по мере загрузки, включая данные, полученные после открытия расчёта. Диапазоны и предварительные объёмы пользователь уточняет вручную.
- Масла подбираются по нормализованным характеристикам моторных масел, с приоритетом OEM над ACEA/API/ILSAC. Неизвестный допуск не превращается в подбор только по вязкости.
- Наличие берётся из выбранного склада текущего филиала; товары другого филиала недоступны. API требует авторизацию и доступ к филиалу. В ответе нет закупочных цен.
- Продажа в литрах считается по нужному объёму, продажа канистрами округляется до целого числа упаковок. Без объёма фасовки или положительной цены товар выбрать нельзя.
- Одинаковая линейка масла в разных фасовках объединяется в один вариант. Для нужного объёма подбирается комплект доступных упаковок с минимальным излишком, затем с минимальной стоимостью. Например, 4 л и 1 л образуют один комплект на 5 л. Разные линейки и продажа на розлив остаются отдельными вариантами. Расходники и работа общие для всех вариантов. Найденные масляный, воздушный и салонный фильтры MANN доступны прямо в расчёте: при выборе совместимого складского товара фильтр сразу добавляется в расчёт; цена редактируется прямо рядом с выбором. При открытии расчёта для каждого артикула MANN автоматически запрашиваются предложения Роско: исходный MANN и его прямые аналоги из `crosses.Part`. Посторонние результаты поиска и аналоги второго уровня не включаются; одинаковые складские предложения объединяются. Допускаются только положительные цена и остаток, без комплектов с кратностью больше единицы. Показаны розничная цена с наценкой филиала, остаток у поставщика и интервал даты и времени доставки в часовом поясе филиала (или срок в днях, если даты отсутствуют); неизвестный срок обозначается явно. Закупочная цена в браузер не передаётся. Предложения можно сравнить в раскрываемом списке и отсортировать «Дешевле» или «Быстрее» без повторного запроса. По умолчанию предложения идут по ближайшей доставке, затем по цене; тот же порядок используется в списке выбора товара. Если исходный MANN недоступен, сравнение аналогов открывается автоматически. Неизвестный срок стоит после известных при сортировке по доставке. Аналоги явно подписаны как связи Роско; применяемость нужно сверить с автомобилем. При выборе сохраняются реальный бренд и артикул аналога, цена, срок и исходный артикул MANN; они попадают в расчёт и сообщение клиенту. Кнопка «Обновить Роско» повторяет запрос. При ошибке интеграции складские и ручные варианты остаются доступны. Можно также добавить найденный артикул MANN и указать цену. Поиск товара/услуги по названию или артикулу и ручные строки тоже доступны.
- Изменение требований очищает выбор масла. Изменение автомобиля или модификации сбрасывает расчёт. Склад можно выбрать прямо из расчёта: открываются параметры документа. При выборе или смене склада параметры масла, ручные строки и артикулы MANN без привязки к наличию сохраняются; складские предложения очищаются. Расчёт сохраняется в состоянии страницы отгрузки, без записи в базу; сворачивание расчёта или закрытие автоподбора не удаляет выбранные строки. При уходе со страницы предложение нужно скопировать. Можно подготовить предложение только с фильтрами/работой без выбора масла.
- Кнопка копирует сообщение с составом каждого варианта и итогом; ручное копирование из предварительного просмотра доступно при ограничениях буфера обмена.

Расчёт предварительный: остатки не резервируются, документы и оплаты не создаются. Применяемость выбранного фильтра подтверждается существующим подбором фильтров; поиск по складу сам по себе не подтверждает совместимость.

Проверки: `npm run test:maintenance-quote`, TypeScript, ESLint изменённых новых модулей. Браузерный сценарий проверен на реальном компоненте с изолированным демонстрационным API, включая два варианта, фильтр, работу, копирование и ширину 390 px. Проверка с рабочей базой и публикация отдельно.

В сохранённой отгрузке данные прежнего VIN-подбора передаются как подсказки; диапазон объёма не выбирается автоматически. В Роско отправляются только явно распознанные артикулы MANN, не OEM-номера других брендов. Складские варианты ограничиваются складом документа. Артикул MANN, введённый вручную, помечается как требующий проверки применяемости.
