# Расчёт ТО в подборе автомобиля

В оформлении обслуживания после подтверждения автомобиля под блоком технических жидкостей доступна кнопка «Рассчитать ТО».

- Допуск, вязкость и объём выбираются через компактные поля с поиском по вводу: показываются максимум восемь подсказок, доступны выбор мышью и стрелками/Enter, закрытие Escape и ввод собственного значения. Нормализованные значения выбранного автомобиля показаны первыми; ниже доступны общие справочники. Для нестандартных значений есть ручной ввод.
- Единственный нормализованный допуск, вязкость и точный объём проверенного профиля подставляются по мере загрузки, включая данные, полученные после открытия расчёта. Диапазоны и предварительные объёмы пользователь уточняет вручную.
- Масла подбираются по нормализованным характеристикам моторных масел, с приоритетом OEM над ACEA/API/ILSAC. Неизвестный допуск не превращается в подбор только по вязкости.
- Наличие берётся из выбранного склада текущего филиала; товары другого филиала недоступны. API требует авторизацию и доступ к филиалу. В ответе нет закупочных цен.
- Продажа в литрах считается по нужному объёму, продажа канистрами округляется до целого числа упаковок. Без объёма фасовки или положительной цены товар выбрать нельзя.
- Каждый выбранный товар масла является отдельным вариантом предложения. Расходники и работа общие для всех вариантов. Найденные масляный, воздушный и салонный фильтры MANN доступны прямо в расчёте: для каждого выбирается совместимый складской товар с наличием и ценой. Если складского товара нет, можно добавить найденный артикул MANN и указать цену. Поиск товара/услуги по названию или артикулу и ручные строки тоже доступны.
- Изменение требований очищает выбор масла. Изменение автомобиля или модификации сбрасывает расчёт. Склад можно выбрать прямо из расчёта: открываются параметры документа. При выборе или смене склада параметры масла, ручные строки и артикулы MANN без привязки к наличию сохраняются; складские предложения очищаются. Расчёт сохраняется только в состоянии открытого подбора, без записи в базу.
- Кнопка копирует сообщение с составом каждого варианта и итогом; ручное копирование из предварительного просмотра доступно при ограничениях буфера обмена.

Расчёт предварительный: остатки не резервируются, документы и оплаты не создаются. Применяемость выбранного фильтра подтверждается существующим подбором фильтров; поиск по складу сам по себе не подтверждает совместимость.

Проверки: `npm run test:maintenance-quote`, TypeScript, ESLint изменённых новых модулей. Браузерный сценарий проверен на реальном компоненте с изолированным демонстрационным API, включая два варианта, фильтр, работу, копирование и ширину 390 px. Проверка с рабочей базой и публикация отдельно.
