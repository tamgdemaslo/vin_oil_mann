# Manifest вывода устаревшей складской интеграции

Инвентаризация выполнена read-only до удаления runtime-компонентов. Таблица
фиксирует только объекты старой интеграции; бизнес-сущности не классифицируются
как кандидаты на удаление.

| Объект | Файл/таблица | Назначение | Используется runtime до очистки | Содержит бизнес-данные | Действие |
|---|---|---|---:|---:|---|
| HTTP-клиент и флаги | удалённые модули `src/lib` | Авторизация, вызовы API, feature flags | Да | Нет | DELETE |
| Импорт и синхронизация | удалённые CLI и sync-модули | Импорт, polling, аналитические снимки | Да | Нет | DELETE |
| API-маршруты | удалённое namespace API | Каталог, контрагенты, остатки, картинки | Да | Нет | DELETE |
| Экран интеграций | `src/app/cabinet/integrations/IntegrationsClient.tsx` | Карточка, статус, ручной импорт | Да | Нет | DELETE |
| Sync snapshots | три прежние Prisma-модели снимков отгрузок и состояния аналитики | Курсоры и статус синхронизации | Да | Нет | MIGRATE_THEN_DELETE |
| Внешние поля | прежние поля ссылок и идентификаторов CRM/диагностики | Сопоставление с внешним контуром | Да | Нет | MIGRATE_THEN_DELETE |
| Товары, клиенты, контрагенты, отгрузки, позиции, остатки, цены, документы, касса | `Local*`, CRM и операционные таблицы | Собственные рабочие данные | Да | Да | KEEP_BUSINESS_DATA |
| Старые Prisma migrations | `prisma/migrations/**` до этой задачи | Уже применённая история БД | Нет | Нет | KEEP_HISTORICAL_MIGRATION |
| Переменные и secrets | env templates, Timeweb, GitHub | Доступ прежнего провайдера | Да | Нет | MANUAL_SECRET_REMOVAL |

После очистки source-кода работающие функции используют внутренние IDs и
relations локальной PostgreSQL. Старые физические колонки остаются в БД до
согласованной forward-only миграции, но исключены из Prisma schema и не
доступны runtime.
