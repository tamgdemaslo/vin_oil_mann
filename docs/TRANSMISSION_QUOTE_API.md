# Заявки на расчёт замены масла в АКПП

Форма: `/booking/transmission-quote?case=<case-id>`. Кнопка находится в наряд-заказе на странице кейса.
Использует стили и шапку основной записи, но не занимает время в расписании.

## API

`POST /api/public/leads`, JSON, без авторизации посетителя.

```json
{
  "intent": "transmission_oil_quote",
  "name": "Иван",
  "phone": "+79991234567",
  "vehicle": "Toyota Camry, 2019",
  "vin": "",
  "comment": "Пробег 95000 км",
  "sourcePage": "/case/toyota-camry-70-u760",
  "utm": {"utm_source": "example"},
  "website": ""
}
```

Обязательны имя (от 2 символов), корректный телефон и автомобиль. VIN необязателен; если передан — 17 латинских букв и цифр без I, O, Q. Комментарий необязателен. `website` — скрытое антиспам-поле, должно быть пустым.

Успех: HTTP 201, `{ "ok": true, "lead": { "id": "…", "stageId": "…", "status": "…" } }`.
Ошибки: 400 — данные, 403 — недопустимый Origin, 429 — лимит, 500 — сохранение недоступно.
Форма показывает подтверждение только после успешного ответа API.

Заявка сохраняется в существующей CRM как `crmDeal` с названием «Расчёт замены масла в АКПП», источником `client-site`, первой стадией воронки и следующим действием «Рассчитать стоимость и связаться с клиентом». В заметках сохраняются контакты, автомобиль, VIN, услуга, комментарий, страница кейса и UTM. Новая схема БД не требуется. Другие обращения без этого intent сохраняют прежнее поведение.

В отдельном клиентском приложении (`CLIENT_SITE_ONLY=true`) `/api/public/leads` делегируется на существующий HTTPS backend `PUBLIC_CLIENT_VIN_ORIGIN` так же, как API записи. Origin проверяется до делегирования. Доступ к чтению CRM остаётся авторизованным.

Существующие настройки: `PUBLIC_API_LEAD_LIMIT_PER_HOUR` (по умолчанию 5/IP/час), `PUBLIC_CLIENT_ORIGINS`, `PUBLIC_LEAD_RESPONSIBLE_LOGIN`.

Для направления заявок в филиал используется существующая публичная витрина (`PUBLIC_STOREFRONT_SLUG`). По умолчанию — первый активный филиал витрины по её сортировке. `PUBLIC_LEAD_BRANCH_ID` позволяет назначить другой филиал из этой же витрины. Филиал из тела запроса не принимается. Заявки расчёта имеют `caseType=calculation`, `caseStatus=calculation_needed` и входят в счётчик «Нужно рассчитать» в шапке «Клиенты».
