## Что исправлено в алгоритме автомобиля

1. Год начала поколения TRONK больше не принимается за фактический год автомобиля. В аудите приоритет имеет год из исторической карточки, а значение провайдера сохраняется только для диагностики.
2. Добавлены поколения `XI`–`XV`, семейства коротких кодов двигателя (`Z6` ↔ `Z601/Z627`) и совместимость подробного кода кузова с семейством (`ZRE182` ↔ `E18`, `ADT250` ↔ `T25`).
3. Добавлены рыночные алиасы `New Actyon → Actyon`, `GLK 300 → GLK`, `Land Cruiser 200 V8 → Land Cruiser`, `BMW 520D → BMW 5` и длинная группа MANN `Mini Cooper II,... → Cooper`.
4. Обозначения двигателя и комплектации (`V8`, `520D`, `1.4TSI`) больше не принимаются за коды кузова.
5. Служебные строки PDF — коробка, климат, сторона установки, экспортное исполнение и `All models` — исключены из списка модификаций.
6. При конфликте модели, поколения, кода двигателя, объёма, топлива или года автоматический выбор запрещён. Неполное, но правдоподобное совпадение остаётся на подтверждение.

## Что исправлено в локальном сопоставлении фильтров

1. Сначала учитывается сохранённая ручная связь `ProductMannLink` в рамках текущих организации и филиала.
2. Затем проверяется точное нормализованное совпадение с `article` и `code` товара.
3. Затем — точный токен в `OEM Parts`.
4. Название используется только как точный нормализованный токен; совпадение по подстроке запрещено, чтобы, например, `W67/2` не совпал с `W6720`.
5. Если сильных товаров несколько, статус остаётся `multiple_matches`. Лучший кандидат сортируется по уверенности и доступному остатку, но неоднозначность не скрывается.

В этой выборке уже существовало 5 активных ручных связей, но ни одна не потребовалась для получения результата: все 27 найденных сопоставлений воспроизводятся по артикулам, кодам, OEM и точным токенам названия.

## Повторный запуск

```bash
npm run audit:mann-filter-local-matching -- \
  --vehicle-records=/path/to/local-demands-data.sql \
  --mann-catalog=/path/to/mann-filter-applications-data.sql \
  --local-products=/path/to/local-products-data.sql \
  --local-stock=/path/to/local-stock-balances-data.sql \
  --mann-links=/path/to/product-mann-links-data.sql \
  --lookup-cache=/path/to/vehicle-lookup-cache-data.sql \
  --live-decode
```

`--live-decode` передаёт госномера внешнему провайдеру и должен использоваться только после явного разрешения.
