# ИИ-агент «Там где масло»

Агент работает поверх общего `messenger_conversations`, поэтому сценарий не зависит от Telegram. Канал выбирается по записи диалога и настройке организации; новые адаптеры WhatsApp, VK, Avito и MAX подключаются к мессенджерному шлюзу без изменения расчёта, сессии или инструментов.

## Безопасный путь расчёта

1. Агент получает контекст клиента и автомобиля и задаёт один недостающий вопрос.
2. Для технического подбора он сначала сообщает клиенту о проверке, затем использует только серверный `trusted_technical_web_search`.
3. Поиск записывает проверяемые факты в `ai_agent_technical_evidence`: автомобиль, источник, URL, выдержку, дату, уверенность, версию и срок актуальности.
4. Детерминированный `calculate_service_quote` читает только актуальные цены каталога; модель не суммирует деньги в тексте.
5. `request_quote_approval` всегда останавливает сценарий до отправки. Панель сотрудника показывает подготовленный текст, сводку и источники.
6. После подтверждения и явного согласия клиента запись требует VIN. Она создаёт запись на «Дачная, 6В» и черновик отгрузки без резерва остатков.

При расхождении источников технический результат не используется: расчёт получает `needs_human_review`, а сотруднику передаётся резюме.

## Технический поисковый провайдер

Свободный браузер модели намеренно не используется. Для реального поиска укажите:

```bash
TECHNICAL_SEARCH_ENDPOINT=https://technical-search.internal/v1/search
TECHNICAL_SEARCH_TOKEN=...
```

Провайдер получает POST с `vehicle`, `aggregate`, `factTypes` и `trustedDomains`; возвращает только извлечённые факты и цитаты:

```json
{
  "facts": {
    "requiredApproval": "Ford WSS-M2C913-D",
    "allowedViscosities": ["5W-30"],
    "volumeWithFilter": 5.7
  },
  "sources": [
    {
      "name": "Ford service documentation",
      "url": "https://…",
      "excerpt": "…",
      "confidence": 0.93,
      "validUntil": "2027-01-01T00:00:00.000Z"
    }
  ],
  "conflicts": []
}
```

Источник принимается только если его домен есть в `trustedDomains` настройки агента. Если провайдер не настроен или не вернул источник, агент не подменяет его памятью: просит точечное уточнение, делает предварительный сценарий при достаточных данных либо передаёт сотруднику.
