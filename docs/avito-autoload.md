# Автовыгрузка масел в Авито

Подключение находится в **Управление → Интеграции → Авито · товары** (`/cabinet/integrations#avito`). Товары, редактор объявлений и история находятся в **Склад → Авито** (`/warehouse/avito`). Раздел поддерживает моторные и трансмиссионные масла, выбранные через существующий признак `LocalProduct.avito`. Данные товара, складская цена и технические характеристики остаются источником; отдельные правки объявления хранятся независимо.

## Подготовка

1. Выбрать конкретный активный филиал и открыть блок «Авито · товары» в «Интеграциях». Ввести Client ID и Client Secret и нажать «Сохранить и проверить». Ключи сохраняются зашифрованными, после чего проверяется доступ к профилю автозагрузки и определяется номер аккаунта Авито. Если площадка недоступна или отклонила ключи, сохранение не отменяется: причина отображается в блоке подключения, проверку можно повторить отдельно.
2. Указать HTTPS-домен CRM, доступный извне, и адрес из профиля Авито либо его идентификатор. Домен публичного клиентского сайта использовать нельзя: его маршруты ограничены витриной.
3. Выбрать склады и правило исключения товаров по доступному остатку после резервов. По умолчанию исключение включено, порог равен нулю. Количество не передаётся в Авито: оно управляет включением объявления в файл.
4. Выбрать товары, исправить ошибки и сформировать первый CSV. Проверить файл в кабинете Авито перед первой рабочей загрузкой.
5. Включить выдачу файла по ссылке и добавить ссылку в профиль автозагрузки Авито. Расписание и тариф настраиваются в кабинете площадки. По умолчанию используется только оплаченный пакет; продвижение выключено.
6. Для запуска обработки открыть «Настройки выгрузки и ссылка на файл», подключить файл к Авито и запросить обработку. Отчёт можно получить прямо в «Интеграциях», а результаты объявлений — посмотреть в складском разделе. Запрос обработки файла ещё не подтверждает публикацию.

Ключи не нужны для ручного подключения постоянной ссылки в Авито. Live API и публикация требуют проверки на конкретном аккаунте; локальные тесты используют подставные ответы и не обращаются к площадке.

При первом сохранении ключей на HTTPS-сайте домен CRM подставляется автоматически. Автовыгрузка при этом выключена. Замена ключей сохраняет существующий домен, токен ссылки, адрес, склады и правила размещения. Статус подключения сбрасывается до новой проверки. Настройки API загружаются через отдельный `/api/integrations/avito` без чтения товарного каталога; проблемы товаров не мешают подключить аккаунт.

## Товарные группы, фильтры и сортировка

В списке показываются товары групп моторных и трансмиссионных масел. Связанная `LocalCatalogGroup` имеет приоритет над старым `groupPath`; для товаров без связанной группы используется сохранённый путь группы. Название самого товара, технические признаки и отметка «Авито» не определяют его принадлежность к маслам. В частности, «Масляные фильтры АКПП», фильтры CVT и поддоны не считаются трансмиссионным маслом. Отметка «Авито» управляет включением подходящего масла в файл, а отдельный тип в старой правке объявления не меняет категорию, заданную группой карточки товара.

Над таблицей доступны независимые фильтры категории Авито, реальной товарной группы, состояния объявления и фотографий. Можно одновременно выбрать ошибки и отсутствие фото. Фотографии оцениваются по выбранным снимкам объявления с назначением Авито; отключённые фото не считаются добавленными. Сортировка поддерживает название в обе стороны, ошибки в начале, отсутствие фото в начале, готовые к выгрузке в начале, цену и остаток в обе стороны. Фильтрация и сортировка применяются ко всему каталогу филиала до пагинации по 250 товаров. При равенстве основного признака порядок закреплён названием и ID товара.

## Адрес, заголовки и шаблоны

Аккаунт, ключи, адрес и шаблоны принадлежат текущему филиалу. У «Дачной» и «Гагарина» независимые подключения. По умолчанию адрес берётся из настроек филиала, включая при выдаче публичного файла. Для двух существующих точек известные адреса подставляются также по точному имени филиала, когда его адрес ещё не заполнен: Калининград, ул. Дачная, 6В и ул. Юрия Гагарина, 116. Для другого филиала адрес не угадывается. Можно выбрать отдельный адрес для Авито или указать идентификатор адреса своего аккаунта. Ранее введённые непустые адреса сохраняются как отдельные; старые пустые настройки наследуют адрес филиала.

В «Настройки выгрузки и ссылка на файл → Заголовки и описания» настраиваются общий шаблон заголовка и автоматическое сокращение до 50 символов. Сначала из длинного заголовка удаляются разрешённые фразы (по умолчанию «моторное масло», «масло моторное», «трансмиссионное масло», «масло трансмиссионное»), затем текст сокращается по границе слова. Unicode считается по символам; короткие заголовки сохраняются. Изменение применяется ко всем объявлениям без отдельного заголовка и не переименовывает карточки товаров.

Описание использует общий шаблон либо отдельный шаблон категории «Моторные масла» / «Трансмиссионные масла». Пустой шаблон категории наследует общий. Например:

```text
«Там где масло» — магазин масел и автосервис.

{описание}

Забрать товар можно по адресу: {адрес}.
```

Поддерживаются `{название}`, `{описание}`, `{заголовок}`, `{бренд}`, `{артикул}`, `{вязкость}`, `{объём}`, `{цена}`, `{адрес}`, `{телефон}`. Для заголовка доступны название, бренд, артикул, вязкость и объём. `{описание}` вставляет описание карточки товара; если оно пустое, используются характеристики масла. Подстановка выполняется один раз: текст карточки не интерпретируется как шаблон. Неизвестные переменные не сохраняются. Предпросмотр загружает реальный товар выбранной категории и пересчитывается при редактировании шаблона.

Отдельные заголовок и описание в редакторе объявления имеют приоритет над шаблонами. «Использовать шаблон» возвращает соответствующее поле к общим правилам. Итоговое описание проверяется после подстановки: превышение 7 500 символов останавливает выдачу, текст не обрезается. Те же правила используются в редакторе, ручном CSV и публичном файле Авито.

## Требования и формат

Справочники производителя, SAE и объёма получены из предоставленных официальных XLSX-шаблонов от 12.10.2026. Их имена и SHA-256 записаны в `src/lib/avito-autoload/catalogs.generated.json`. Скрипт `scripts/generate-avito-autoload-catalogs.py` обновляет справочники из двух исходных файлов без изменения самих книг.

CSV использует русские названия параметров, UTF-8 с BOM и экранирование запятых, кавычек и переносов строк. Он объединяет поля двух категорий: ACEA заполняется для моторного масла, ATF — для трансмиссионного. Допуски разделяются `|`; составные значения с `/` сохраняются целиком. Требуется хотя бы один блок ACEA/API/OEM либо ATF/API/OEM соответственно. Справочников самих допусков в исходных шаблонах нет, поэтому их допустимость дополнительно проверяет Авито.

Заголовок ограничен 50 символами, описание — 7 500. Цена задаётся целыми рублями: копейки не округляются автоматически. Отсутствие фотографий даёт предупреждение. До 10 выбранных фотографий с назначением `AVITO` выдаются площадке как JPEG; фотографии витрины не используются. Автоматическое объединение вариантов выключено до явного выбора пользователя.

Для товаров с единицей продажи «литр» объём бочки и цена за литр не превращаются автоматически в объявление о продаже всей бочки. Нужно явно задать объём продажи и цену за весь выбранный объём. Доступный остаток за вычетом сервисного порога должен покрывать этот объём.

## Хранение и доступ

Новые таблицы и миграции не нужны. Настройки, правки, результаты Авито и текущий состав выгрузки хранятся в `IntegrationCredential` с каналом `avito_autoload`, с использованием существующего шифрования интеграций. События и исходные файлы выгрузок — в `IntegrationAuditLog`. История скачивает сохранённый файл, а не пересчитывает его по сегодняшним ценам.

Работа разрешена только в точном контексте филиала. Чтение, редактирование и изменение секретов проверяются отдельно. Публичная ссылка содержит защищённый токен, связанный с сохранённым профилем и активным филиалом. Она предоставляет доступ только к составу выгрузки и выбранным фотографиям; её следует передавать своему аккаунту Авито. Замена токена доступна владельцу через `rotateFeedToken` в операции сохранения настроек и требует обновления ссылки на площадке.

Для production используется существующий `MESSENGER_CREDENTIAL_ENCRYPTION_KEY` (либо настроенный ключ из штатной цепочки шифрования). Ключ должен быть постоянным и храниться в переменных Timeweb, не в репозитории. Потеря или замена ключа делает прежние токены и зашифрованные настройки недоступными.

Идентификатор объявления зависит от филиала и ID товара, сохраняется при переименовании или изменении цены. Номер существующего объявления можно указать в редакторе отдельно.

## Обработка ошибок

Выбранный товар с ошибкой останавливает выдачу всего файла: сервер возвращает `503`, а не удаляет объявление незаметно. Ошибки чтения базы и расшифровки также не превращаются в успешный пустой файл. Исключение по остатку действует только при включённом правиле. Пустая выгрузка после снятия выбора требует явного подтверждения; первый файл не может быть пустым.

Наличие ссылки и доступ к API сами по себе не включают выдачу CSV. В настройках платформы нужно сохранить включённую «Разрешить автовыгрузку по ссылке» и сформировать первый файл в «Склад → Авито». Рядом со ссылкой показывается, какое из этих условий ещё не выполнено. Ошибочный публичный ответ использует `text/plain`, содержит понятную причину и код в `X-Avito-Feed-Status`: `AVITO_FEED_PAUSED`, `AVITO_FEED_NOT_REVIEWED`, `AVITO_INVALID_LISTINGS` или `AVITO_FEED_UNAVAILABLE`. Та же причина сохраняется в истории запросов файла. Внутренние ошибки базы и секреты не раскрываются. `HEAD` проверяет файл по тем же правилам, что и `GET`, но не обновляет снимок и историю загрузок.

API подключает нашу ссылку с сохранением других файлов, расписания и ограничений профиля. Запросы публикации не повторяются автоматически. Статусы «опубликовано» показываются только по результатам Авито, отдельно от готовности данных.

## Проверка

`npm run test:avito-autoload` проверяет CSV, словари, цены и остатки, постоянные ID, роли, изоляцию филиалов, защищённые токены, неизменяемую историю, обработку отказов и API на подставных ответах. Дополнительно выполняются проверка TypeScript, ESLint, навигации и штатный `test:branch-isolation`.

Развёртывание выполняется обычным процессом Timeweb App Platform. Эта реализация не подключает рабочий аккаунт Авито и не запускает размещение автоматически.
