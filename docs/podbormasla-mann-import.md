# Импорт жидкостей и допусков в каталог MANN

Импортёр объединяет снимок `podbormasla.ru` с вариантами автомобилей из каталога MANN. Исходные строки сохраняются без потерь, а распознанные объёмы, допуски, вязкости, интервалы замены и узлы записываются отдельно в нормализованном виде.

## Таблицы

- `fluid_catalog_import_batches` — история запусков и контрольная статистика.
- `fluid_source_rows` — исходные строки сайта и все их ячейки в JSON.
- `vehicle_fluid_requirements` — нормализованные требования по автомобилю и узлу.
- `mann_fluid_requirement_links` — кандидаты связи требования с `vehicleVariantKey` каталога MANN.

Связь с MANN не создаётся только по названию модели. Скоринг учитывает марку, модель, поколение, пересечение годов, код и объём двигателя, мощность и тип топлива. Точная связь получает статус `auto_matched`; неоднозначные кандидаты сохраняются как `review_required`; отсутствие подходящего варианта не мешает импорту самого требования.

## Проверка без записи в БД

```bash
npm run import:podbormasla
```

Команда автоматически берёт последние каталоги `outputs/podbormasla-*` и `outputs/mann-pdf-catalog-*` и создаёт:

- `podbormasla_mann_match_report.json` — агрегированная статистика;
- `podbormasla_mann_match_review.csv` — все требования и лучшие кандидаты MANN для проверки.
- `podbormasla_mann_match_review_contexts.csv` — компактная очередь: одинаковое решение для всех узлов одного автомобиля и двигателя собрано в одну строку; поля `decision` и `note` оставлены для подтверждения.

Можно явно передать пути:

```bash
npm run import:podbormasla -- outputs/podbormasla-20260723 \
  --mann-dir=outputs/mann-pdf-catalog-2026-07-16 \
  --report-dir=outputs/podbormasla-20260723
```

## Запись в PostgreSQL

Сначала применить миграцию обычным способом проекта, затем запустить:

```bash
npm run import:podbormasla -- --apply
```

Режим `--apply` сначала повторяет полную контрольную проверку, убеждается, что связанные `vehicleVariantKey` существуют в текущей БД MANN, и только после этого атомарно заменяет предыдущий набор строк источника. Повторный запуск не размножает данные.

Для выдачи данных по уже найденному MANN-варианту используется `listFluidRequirementsForMannVariant(vehicleVariantKey)`. По умолчанию функция возвращает подтверждённые и автоматически сопоставленные требования; кандидаты ручной проверки можно включить отдельным параметром.
