# Единый остаток разливного масла

После сверки с инвентаризацией `warehouseLinked` связывает внутренний остаток текущей бочки со складским количеством. Это локальный учёт; корректировки не отправляются в ГИС МТ автоматически.

- Склад — источник фактического количества. Открытая бочка получает складской остаток минус сумма запечатанных бочек на том же складе.
- Инвентаризация (включая строку без складского расхождения), её отмена, приёмка и списание обновляют оба остатка в одной транзакции. История сохраняется в журнале маркировки и событиях бочки.
- Проведение отгрузки уменьшает склад и бочку один раз. Ledger сохраняет код конкретной бочки; кассовая очередь проверяет этот снимок и не списывает литры повторно. Чек последних литров доступен при нулевом текущем остатке.
- Возврат отгрузки восстанавливает оба остатка. Возврат после смены бочки блокируется, чтобы масло не оказалось в другой ёмкости.
- Несколько открытых бочек, несколько складов без учёта ёмкостей или остаток вне вместимости требуют распределения по бочкам; операция полностью откатывается.
- Ручное изменение связанного остатка через настройки маркировки запрещено. Для изменения количества используется складской документ или инвентаризация.

Старый кассовый счётчик остаётся совместимым для товаров, которые ещё не сверены. Старые проведённые отгрузки без сохранённого кода не получают его задним числом: для нового кассового задания требуется проверка документа. Уже созданные кассовые задания продолжают использовать свой сохранённый payload.

Проверка: `npm run test:bulk-oil-unified-stock` с одноразовой локальной базой `eco_barrels_test`.
