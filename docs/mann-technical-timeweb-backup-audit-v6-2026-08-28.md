## Почему результат стал безопаснее

Последовательно добавлены консервативные ограничения:

1. Опасные межсистемные совпадения исключены: гидравлика, ГУР, дифференциалы и трансмиссии больше не получают автоматические связи из широких или неоднозначных групп.
2. Для моторного масла и охлаждающей жидкости требуется точное подтверждение двигателя; недостаточно совпадения только марки, модели или поколения.
3. Источники с широкими группами автомобилей и загрязнённый PDF-контекст не допускаются к автоматической материализации.
4. Если в одной строке указаны разные объёмы для разных двигателей, коробок, приводов, годов или комплектаций, запись уходит в review до структурирования условия.
5. Обозначения мощности в `л.с.` не интерпретируются как литры: обнаружено и отклонено 9 таких токенов, ошибочно разобранных как объём — 0.

## Выборочная проверка

Сформированы две перекрывающиеся выборки по 200 строк: обычные `ACTIVE` и наиболее рискованные системы. После устранения пересечения проверено 248 уникальных ассоциаций.

| Вердикт проверки Codex | Количество |
|---|---:|
| `APPROVE` в пределах проверки применимости и безопасности парсинга | 183 |
| `REVIEW` | 65 |
| `REJECT` | 0 |

Эта проверка не является независимой человеческой приёмкой и не подтверждает официальный технический факт. Все критические флаги оставлены вне `APPROVE`; итог проверки: `PASS_CODEX_REVIEW_HUMAN_SIGNOFF_STILL_REQUIRED`.

На отдельном наборе из 30 размеченных случаев ложных положительных автоматических связей не найдено. При этом три заранее одобренных случая алгоритм не материализовал: Mazda CX-9 II / раздаточная коробка, Honda Civic IX / МКПП и Mazda CX-9 II / охлаждающая жидкость. Получена precision-безопасность без полноты: false positive — 0, false negative — 3, recall — 0 на трёх положительных случаях.

Retrieval-проверка на 200 старых уникальных связях показала top-1 83,5%, top-3 94%, top-20 100%. Это только legacy proxy, не независимый golden truth, поэтому показатель не разрешает запуск.

## Блокирующие причины NO-GO

1. 65 из 248 проверенных ассоциаций всё ещё требуют ручного решения.
2. Проверка Codex не заменяет независимую человеческую сверку с официальным источником.
3. Retrieval измерен на legacy proxy, а не на полноценном golden/manual truth set.
4. Безопасное покрытие трансмиссий, редукторов, раздаточных коробок и полного основного профиля равно нулю.
5. Алгоритм пропускает три известных положительных случая, то есть текущая полнота недостаточна.

Миграцию, запись 715 предварительных `ACTIVE`-связей и переключение runtime выполнять нельзя. Следующий разрешённый этап — независимая ручная проверка 65 строк, затем отдельное решение по golden set и покрытию опасных систем.
